# multilingual-question-answer-generation-system
This is my project titled “Multilingual Question-Answer Generation System.”

The main objective of this project is to automatically generate meaningful and contextually relevant Question-Answer pairs from a document.

The system accepts text-based PDF, DOCX, and TXT files as input.

After processing the document, the system generates Question-Answer pairs in English, and then provides corresponding versions in Hindi and Marathi.

Finally, all the generated Question-Answer pairs are stored in a single Excel file named Multilingual_QnA.xlsx.

The project is developed using Python, Streamlit, OpenPyXL, document-processing libraries, and the Google Gemini API for AI-based Question-Answer generation and translation.
